# Ingage LMS

A full-stack Learning Management System built with:

Frontend
- React
- JavaScript
- Tailwind CSS

Backend
- Java
- Spring Boot
- Spring Security
- JWT
- OAuth2

Database
- PostgreSQL

Features
- User Registration
- Email OTP Verification
- Login
- Google OAuth
- LinkedIn OAuth
- Forgot Password
- Password Reset
- Career Paths
- Courses
- Learning Progress
- Projects
- Opportunities
