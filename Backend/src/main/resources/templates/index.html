Technology Version Layer Actual Purpose in LMS Backend
Java 21 / 26 Programming Language Core object-oriented backend programming runtime.
Spring Boot 3.4.x Web Framework REST controller mapping, dependency injection, and embedded Tomcat application server.
Spring Security 6.x Security & Access Control Stateless JWT token authentication filter, BCrypt password hashing, and role-based authorization.
Spring Data JPA Hibernate 6.x Persistence / ORM Repository abstraction, entity mapping, and automated PostgreSQL schema synchronization.
PostgreSQL 16.x Relational Database Persistent storage for user profiles, courses, enrollments, certificates, and payment records.

Razorpay SDK 1.4.x Payment Gateway Razorpay order creation, payment signature verification, and webhook transaction processing.
Thymeleaf 3.1.x Template Engine Embedded view rendering for this backend documentation dashboard.
Project Lombok 1.18.x Developer Tooling Boilerplate reduction for entity and DTO getters, setters, builders, and constructors.

Security Configuration & Secrets Sanitization

Spring Security filter chain, JWT Bearer tokens, and OAuth2 security

Secrets Protection Status

All sensitive application credentials, tokens, and database passwords are sanitized and never exposed:

Secret Key Configuration Source Status Exposure Prevention
JWT_SECRET application.properties (jwt.secret) Configured ✓ Masked with HMAC256 signature verification in filter
SPRING_DATASOURCE_PASSWORD application.properties / Environment Configured ✓ Managed by HikariCP; never rendered
MAIL_PASSWORD application.properties (spring.mail.password) Configured ✓ Google App Password safely masked
GOOGLE_CLIENT_SECRET application.properties (spring.security.oauth2) Configured ✓ Exchanged server-to-server only
LINKEDIN_CLIENT_SECRET application.properties (spring.security.oauth2) Configured ✓ Exchanged server-to-server only

Authentication Architecture (Non-SMTP)

Direct registration, secure password hashing, and database-backed OTP without external SMTP dependencies
Component Implementation Status Operational Architecture
External SMTP Dependency Completely Removed Zero external SMTP network calls; no socket timeouts or mail credential exposures
Signup Flow Direct Creation Instant user account creation in PostgreSQL with BCrypt password hashing, no waiting for OTP
Login Flow Email & Password Direct authentication issuing stateless JWT Bearer token and HttpOnly session cookies
One-Time Code (OTP) Database-Backed Managed via OtpVerification entity with 5-minute expiry and attempt throttling without SMTP
